            \item \textbf{クライエントは自分自身の専門家}
            \item 援助者は\textbf{「同伴者」}（話す量は相手より少ない）
            \item 忠告より\textbf{探求}、説得より\textbf{興味と支援}
          \end{itemize}
        };

          \begin{itemize}\setlength{\itemsep}{3pt}
            \item \textbf{レスリングではなく社交ダンス}
            \item 力でフォール勝ちせず、相手と共に動く
            \item 援助者が\textbf{巧みにリード}しつつ協働する
          \end{itemize}
        };
