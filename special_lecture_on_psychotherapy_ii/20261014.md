# 午前の部 社会的カモフラージュの復習と動画視聴

* 社会的カモフラージュは診断関係なくASDの方たちは用いる。
* ICD-11の原版では、ASDの診断基準へのコメントに、社会的カモフラージュがあっても生活上に困難さがある場合は診断するのが適切というコメントがある。

## オールマイノリティ
* 多様性のある社会、それぞれマイノリティの部分がある。マジョリティがあるからといって威張るのではない（動画の大島先生）。造語。
  * 人と違うからと言って闇雲に批判してはならない。
  * 少数派は多数派をいじめない（逆も然り、かな？）、不均衡を解消したい、という思いがある。
* マイノリティには、「権限がない」ということも意味として付与している。
* 福祉にお金がかかっていない
  * なけなしのお金を配布 → 奪い合いになる
  * 生活保護が進まない
  * → 政治が福祉・教育にお金をかければ、全体の福祉が向上するのではないか。北欧はそれがある程度実現している。

* ただ、マイノリティへの理解は、分かる人にはわかるようになってきている。
* 民主主義、多数決が正しいという考え方だけだと、マイノリティが採用されない
  * 自由主義（リベラリズム）、マイノリティが抑圧されることに制限をかけることが重要

## 社会的カモフラージュのパターン
* 補償
  * ドラマなどを見て人とのやり取りを学習し、披露する
* マスキング
  * ASDの特性を隠す
* 同化
  * 定型発達の価値観を無理に取り入れる
  * 学校は同化を促進しているよねぇ…。
* 日本、ある程度カモフラージュをしている人（適度に）は心身の健康度が最大（抑うつ・不安が一番少ない）というのが特徴。
* キャバ嬢がお客さんに接客、お金が欲しいから、自分の計算のうちでやっている。
* 自分の素を保つ場所があるか、ということが重要。
  * 家族がカモフラージュを期待するとまずいのでは…
* 早期療育、カモフラージュをさせようとすることについては…
  * 定型発達に馴染めるようになればいいという考えの下だが、実証が無い限り副作用が大きいと考えられる。

* ニューロダイバーシティ・アファーマティブ・アプローチ
  * 発達症の特徴を、障害でなく、個性など強みとして見なしていくアプローチ（概して）
  * → ABAを批判するもの
    * ただ、「誰にでも馴れ馴れしくすることはダメよ」という、適切な「躾」、自分のアイデンティティを保ちながら「社会のルールを学ぶ」ということは大事。

* 物事の仕組みを学ぶ → 心の健康が増進する？
  * 学校に参加すると、健康が悪化する子供もいるんじゃない？
* マイノリティ的な考え方、教育領域も必須の考え方。

* 現在のABA、社会性を伸ばすという目的ではある。
  * ニューロダイバーシティの考え方の台頭により、多様性に受容的になり、配慮があればいいという考え方にシフトしつつある。
  * 子どもは成長とともに変わる、という考え方がABAにはある
* 支援者側もマイクロアグレッション、定型に近づける、介入する、こういうのって結構ありがち。ただ、それは本人が望んでいるのか？支援者側の価値観の押し付けなのか？見直していくべき。
  * 自閉症の療育者には「こうするべき」というのがありがち。

# 児童思春期の高機能自閉スペクトラム症者と家族に対する認知行動療法プログラムASDに気づいてケアするプログラムAware and Care for my AS Traits(ACAT) 実際編

* ASDの子の療育のヒントになればいいと思います（大島先生）
* 実施要件
  * CBTの適用は、知能指数が80以上とすることが多い。知的発達症の子どもには、別のアプローチが適していすかもしれない。
  * SDQ 厚労省が出している。親が評価。低い → 適応が良い。ただ、臨床用では、元気な子が自己理解のためにACATをしてもいいので、問われない。
  * ASDが主診断なら、併存疾患があってもよい。ただ、ASDの診断・告知があることが必要。
  * 保護者の精神疾患等の問題がある場合は望ましくない（臨床では）。研究上では、保護者は精神疾患を有していないことと、精神疾患の患者と同居していない。
  * 臨床だと、保護者2名来ても問題ない。保護者のみの参加でもOK。子どものことを理解するという目的でも問題ない！
    * 本人はどう感じているか？と、本人が喋ることがメインだと思ったが、これが本人の理解に繋がる？保護者の場合はどう進める？
      * 滅多に言わないが、「自分の子どもの特性が分からず、どう接したらいいか分からない」と言う親がいる。
        * → 本人の特性、本人にどのような関りができるか、ということを一つ一つ作っていく。
        * 例：子どもが同じ服を着る理由はなんだろう、いろんな服を買っているのに。→ 特性から理解する、ということをする。
  * 回数：困ったことを共有するとき、なかなかうまくいかないときは、臨床用では20回を限度とすることがいい。
  * 対面方式ではどう進める？（デモ動画はオンラインを想定していたものだから、対面ではどうなるのかなー？）
    * 対面とオンラインの違い
      * （後の説明を聞いて、オンラインだとどのような制約があるのかを聞いてみよう）

* 社会的な適応と心理的な適応
  * しぶしぶ学校に行く → 社会的適応はできているかもだが、心理的には適応できていない。
* 修学旅行などの「○○旅行」は、敏感な子は嫌がる。ただ親御さんはそのような行事には参加させたい。このニーズのすれ違いをどうするか、というのがポイント。
* 強み・弱み
  * 例：マイペースさ
    * 他の人のペースに左右されづらいが、置いて行かれてしまうことがある。
  * 強みと弱みは表裏一体 → 特性について外在化し、事例概念化する
    * ASDの特性は弱みが強調されがちなので、事例概念化は好まれる。
  
* ASDについて説明
  * 目立っちゃうことが恥ずかしく思う、どうか？（すり合わせ）
    * 子どもと大人の両方に確認。
    * 目立つこで何が心配か？（子供に確認）
      * → 怒られること。
    * 浮くことを変えることは難しい。具体例をもってきて、それについて子どもはどう思うかを確認。
      * 浮くことが難しいことの説明をTh.が行う。
    * 一般的に言われていること（自閉症に見られる特徴など）を説明し、それが本人にはどのような点で表れているのか、日常生活でどのように表れているのかを確認している。
  * 浮いてしまったとしても、相手に自分の苦手を伝えることは大事。
  * 浮かない練習をしている、という話が出た
    * 浮かないようにするのは苦痛で、どうしても浮いてしまう。浮いても大丈夫なようにしましょう、ということを伝える。
  * 親子でACATに求めるものが違うことがある、それについて、前段階では、どのようにセッションへのモチベーションを持っていくのか、どのように整理されるのか
    * 
  * 本人にとって浮かないでほしい、というのは複雑なのかなと思った。場合によっては、2人を分けたりすることもあるのか？
    * 価値観が離れすぎているときは、親子を別にしてセッションを行うことがある。
    * 基本的には子どもの主訴に寄り添うようにする。「お子さんの困り感に寄り添っていくということでよろしいでしょうか？」「セッションを一緒に受けるでもいいですよ（選択させる）」
    * 本人よりも親がたくさん喋る。親が補助をしてしまう。こういうとき、どうやって本人にこれからやることに方向づけるのか？
      * お母さんもよくしゃべる方。自閉さんは、受け身型（自閉の特性（まだわからないが））だったので、本人に話しかけることを意識していた。
    * 本人の実際と一般論をすり合わせること、本人がどの程度理解しているのかをアセスメントするという目的もある。

* 人付き合いができていない
  * 自己評価と他者評価（人から言われたことがあるかどうか）を分けて聞いている。
    * 外的な不適応なのか、内的な不適応なのか、どの立場で困っているのかを調べるために聞いた。
      * 他者評価と自己評価が乖離している（自分ではいいと思っているのに、良く思われていない；自分は出来ていないのに、周りは何も言わない）。括弧の中で書かれているような、乖離の方向性によって支援の方向性が変わる。
* 本人の困り感はどの程度聞くのが良いのか？
  * 一回目だから、代表的に（主訴として）、自分が認知しているところを聞く。ビデオの子どもでは「人付き合い」について話していた。
* （自分事）自分は関係反応の速さが早いので「ASDある・無しで分けると良くない意味づけをしてしまうことに繋がらないか」というようなことは、杞憂になることがあるし、これは相手の作業なので、相手に委ねてみよう。
* 人付き合いについての特性を聞いているとき、母から「修学旅行に行きたくない」ということを話された。
  * → 本人に、どのような困り感、苦痛があるって予想しているのかを聞く。
  * 「修学旅行に行かない」という選択肢を親子に提示する。
    * 母は抵抗（え、行かないという選択肢はなかった。修学旅行の写真が卒業写真に乗らないのは、、、、）→ 母の意見も尊重し、「その考え方も正しい」と伝えた上で、「行く事のメリットとデメリットを比較すると…」という切り出し方をし、本人が困らないようにすることが大切ということを伝える。
* 「どんな会話なら嫌じゃない？」→「何かを決めるとき」
* 自閉症をタイプとして見ていく（20~30分）。
* カモフラージュを日常的に行っている子。現状はASDではない方になっている。本人がASD側の方が心地いいと気づいていない子もいるのでは？
  * いると思う。日常的にカモフラージュをしている人はASDと気づいていることは少ないが、ワークをやる内に気づいていくこともある。
  * カモフラージュの話を入れてもいいかもね。
* 基本的には、明確に「修学旅行に行きたくない」としているので、母親の価値観が侵食することはないが、侵食してしまう場合は、Th.が明確に「お母さんの考え方も一つだけど、自分の考え方・感じ方も大事だよ」ということを伝える。
* 過剰適応という話が出てきた。これは「社会的カモフラージュ」と同じような意味合いで使った？
  * → そうだと思う。
* 楽し気な雰囲気（心理テストをやっているような感覚、当てはまる、当てはまらない） → 自閉を持っていてもいいんだよ、というメッセージを伝える意図もある。
  * 「初めて自分の特性が認められた」という体験を促すことがあるかもしれない。
* ADHDの場合「ドパミンが少ないから、こうなってしまうんだよ」とユーモラスに話し、その場の雰囲気が和んだ、という事例もある。楽しげにやるのは大事。
